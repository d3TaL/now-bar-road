# Now Bar Road

Личное Android-приложение для Galaxy S25 Ultra / One UI 9: время поездки на общественном транспорте в виджете и экспериментальное уведомление для Now Bar.

## Возможности первой версии

- Импорт маршрутов Яндекс Карт через **Поделиться → Now Bar Road** или вставку ссылки.
- Два маршрута: утренний и вечерний; координаты и промежуточные точки берутся из ссылки.
- Самый быстрый **вариант с общественным транспортом** при каждом обновлении; чисто пешие альтернативы исключаются.
- Полное время из ответа Яндекса, а не сумма отдельных участков. Ожидание и пробки учитываются в той мере, в какой их учитывает источник; отдельной проверки реальных пробок нет.
- Виджет с обоими маршрутами, временем расчёта и ручным обновлением.
- Расписание уведомления: **Пн–Пт 05:30–07:00 и 15:30–18:00, Europe/Moscow**. Праздники и переносы не учитываются.
- Debian-сервер: Python 3.11+, без pip-зависимостей, Docker и Chromium. Рассчитан на личное использование на 1 ядре / 512 МБ.
- Подключение телефона по ссылке `nowbarroad://connect?server=…&token=…`.

## Текущий статус

Это первый прототип. HTTP-получение HTML Яндекс Карт с JSON `state-view` проверено на реальном маршруте. Это **не официальный API** и не подтверждённый бессрочный бесплатный доступ: формат, доступность и условия использования сайта могут меняться. CAPTCHA не обходится, при отсутствии актуального ответа показываются последние данные с отметкой устаревания.

Приложение запрашивает promoted ongoing notification (Android Live Updates). **Появление именно в Samsung Now Bar ещё нужно проверить на телефоне.** В приложении есть двухминутный тест с явно обозначенными фиктивными данными. Постоянная оценка маршрута до начала поездки может не получить системное продвижение. Обычное уведомление и виджет работают независимо от решения системы о продвижении.

## APK — сборка только в GitHub Actions

1. Загрузите этот проект в свой GitHub-репозиторий.
2. Откройте **Actions → Build Now Bar Road APK → Run workflow**, либо отправьте изменения в репозиторий.
3. Workflow запускает серверные тесты, `assembleDebug` и `lintDebug`.
4. Скачайте артефакт **now-bar-road-debug-N**, распакуйте и установите `app-debug.apk` на телефон.

Локальная Android-сборка не требуется. В workflow зафиксированы JDK 17, Gradle 8.13 и Android SDK 36. Debug APK подписывается временным ключом runner: между разными запусками ключ может меняться и для установки может потребоваться удаление предыдущей версии. Стабильную личную подпись добавим через GitHub Secrets после первой проверки.

## Установка сервера

Нужны Debian 12+ с Python 3.11+, доступ sudo и публичный HTTPS-адрес (домен либо адрес в вашей HTTPS-сети). Сервер слушает только `127.0.0.1:8080`; наружу его публикует reverse proxy.

### Установка из репозитория

Репозиторий: [d3TaL/now-bar-road](https://github.com/d3TaL/now-bar-road).

```bash
sudo apt-get update
sudo apt-get install -y git python3
git clone https://github.com/d3TaL/now-bar-road.git now-bar-road
cd now-bar-road
sudo bash server/install.sh https://road.example.com
```

Установщик создаёт пользователя `nowbarroad`, генерирует токен, устанавливает службу `now-bar-road.service` и **выводит ссылку подключения**. Повторная установка сохраняет токен и маршруты.

### Ссылка на установщик

Установщик: [server/install.sh](https://github.com/d3TaL/now-bar-road/blob/main/server/install.sh).

```text
https://github.com/d3TaL/now-bar-road/blob/main/server/install.sh
```

Сам установщик использует соседние файлы сервера, поэтому для установки скачивайте репозиторий целиком, как показано выше.

### HTTPS через Caddy

Если reverse proxy уже есть, направьте домен на `127.0.0.1:8080`. Для нового Caddy на Debian:

```bash
sudo apt-get install -y caddy
```

Добавьте в `/etc/caddy/Caddyfile`, подставив свой домен:

```caddyfile
road.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

DNS домена должен указывать на сервер, порты 80/443 — быть доступны. Затем:

```bash
sudo systemctl reload caddy
curl https://road.example.com/health
```

Ожидается `{"ok": true}`. На 512 МБ используйте имеющийся лёгкий reverse proxy; браузер на сервере не запускается.

### Получить ссылку подключения повторно

```bash
sudo now-bar-road-link
```

Команда загружает `/etc/now-bar-road.env` и вызывает функцию установленного сервиса `road.py --connection-link`. Ссылка содержит токен доступа: передайте её себе лично. В приложении нажмите **«Вставить ссылку подключения»**, затем **«Сохранить и проверить сервер»**. Также поддерживается открытие `nowbarroad://connect` системой Android, если мессенджер разрешает такие ссылки.

### Управление

```bash
sudo systemctl status now-bar-road
sudo journalctl -u now-bar-road -n 50 --no-pager
sudo systemctl restart now-bar-road
```

- Код: `/opt/now-bar-road/server/road.py`.
- Настройки: `/etc/now-bar-road.env`, права root-only.
- Маршруты и кэш: `/var/lib/now-bar-road/state.json`.
- Чтобы сменить адрес, измените `ROAD_PUBLIC_URL`, перезапустите службу и получите новую ссылку.
- Для обновления: `git pull`, затем повторный запуск `server/install.sh`.

## Настройка телефона

1. Подключите сервер по ссылке.
2. В Яндекс Картах выберите общественный транспорт и отправьте маршрут в Now Bar Road.
3. Выберите утренний/вечерний слот, задайте название и сохраните. Повторите для второго маршрута.
4. Разрешите уведомления и **точное расписание** кнопками приложения.
5. В системных настройках уведомлений разрешите Live Updates / Now Bar, если такой переключатель доступен.
6. Запустите **«Тест Now Bar на 2 минуты»** и проверьте экран блокировки.
7. Добавьте виджет Now Bar Road на рабочий стол.

Сервер обновляет активный маршрут раз в 5 минут и начинает подготовку за 2 минуты до окна. Ручные запросы к источнику также ограничены одним на 5 минут для каждого маршрута. Телефон использует WorkManager (примерно раз в 15 минут) и будильники на границах окон. При разрешении точных будильников начало планируется точно; сетевое получение и отрисовка могут задерживаться системой. В уведомление встроен срок жизни до конца окна; для надёжности также запланировано снятие. После принудительной остановки Android-приложения откройте его снова, чтобы восстановить фоновую работу.

## API сервера

Все `/v1/*` требуют заголовок `Authorization: Bearer TOKEN`.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | Проверка службы без данных маршрутов |
| GET | `/v1/status` | Оба маршрута и кэш |
| POST | `/v1/routes` | `{"slot":"morning","name":"На работу","url":"https://yandex.ru/maps?..."}` |
| POST | `/v1/refresh` | `{"slot":"morning"}` — обновление с ограничением частоты |

Короткие ссылки поддерживаются только если они перенаправляются на разрешённый домен Яндекса и итоговый URL содержит координаты `rtext` и `rtt=mt`. Остальные варианты пока возвращают понятную ошибку. Фиксированное время отправления и выбранная альтернатива из исходной ссылки не сохраняются: расчёт всегда на текущий момент.

## Проверки сервера

```bash
python3 -m unittest discover -s server/tests -v
```

Тестируются границы расписания, импорт и валидация ссылок, выбор полного минимального времени, исключение пеших альтернатив, отклонение старого ответа, сохранение кэша при ошибках и авторизация HTTP API.
